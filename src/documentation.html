POC Instruction

A static demonstration client for the Instruction catalogue. Records are fictional and remain in this browser.

Recreation notes

Serve the src folder with a static HTTP server. Configure Party and Asset API base URLs in config.js. Search adapters expect JSON responses with an items array.

Domain model

Instructions link a client, legal entity, contact, primary asset, and related assets. Each record has a Mandate, Engagement, or Instruction type, one service line, a lifecycle status, owning office, dates, and optional finance references.

Boundary

The current Party and Asset POCs do not provide general catalogue routes. Empty API configuration therefore uses visible fictional fallback data. This prevents a demo record from being mistaken for live data.
